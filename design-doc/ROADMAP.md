## 已完成的迭代

### ✅ 迭代 1: Git 工具增强
- 新增 Git 命令: pull, reset, merge, init, clone, fetch, stash
- 完善 is_read_only 方法
- 更新工具描述文档

### ✅ 迭代 2: 插件系统 UI 完善
- Web UI 添加 "插件" 标签页
- 插件列表展示（名称、版本、描述、启用状态）
- 插件启用/禁用功能
- 插件详情查看
- 命令面板支持快速切换

### ✅ 迭代 3: 代码库搜索增强
- 支持正则表达式搜索
- 支持文件名搜索
- 搜索结果高亮显示
- 搜索结果显示匹配位置信息

### ✅ 迭代 4: 性能优化
- LRU 缓存优化 token 估算性能
- 智能上下文压缩（梯度压缩策略）
- 统一工具执行超时管理
- 所有工具自动获得超时保护

### ✅ 迭代 5: 用户体验提升
- 增强欢迎页面快捷指令卡片
- 新增"常用工具"区块
- 卡片悬停动画效果
- 代码块复制按钮
- 工具调用结果折叠
